# Q Archive — Desktop App

Offline desktop app for browsing and analyzing the Q post archive.

## Download
Grab the latest installer from the [**Releases**](../../releases/latest) page →
`QArchive-x.y.z-Setup.exe`. Run it; if Windows SmartScreen warns about an
unknown publisher, click **More info → Run anyway**.

This repository hosts the installers and auto-update manifest only — no source code.
