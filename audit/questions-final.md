## The rule

**The requested output decides it, not the mood of the verb.** `Define X.` and `Compare X.` are both imperative; the first asks for information, so the deliverable is an answer — a question. The second asks the reader to perform an analysis, so the deliverable is work — a directive.

- **Q_QUESTION** — `?`, or `Define` / `Identify` / `Explain` / `Describe` / `Clarify` / `List <object>` / `Name <object>`.
- **Q_DIRECTIVE** — `Compare` / `Reconcile` / `Follow` / `Think` / `Read` / `Dig` / `Research` / `Trace` …
- **Q_STATEMENT_OR_HEADING** — `List of Republicans…:` is a noun introducing a list, not a request. Anything ending in `:` is a heading.
- **EDITORIAL_NORMALIZATION** — searchable, carries provenance, `neverDisplayAsQ: true`, never counted.

## Scope note

The review asked for the 34 `NEEDS_CONTEXT` records. Applying the taxonomy to only those would have left the total incoherent: `Reconcile.` and `Compare.` also appear among the 50 `ADD` decisions **and** among the 6,287 already-confirmed units. A word cannot be a directive in one bucket and a question in another, so the taxonomy was applied to every unit and the effect on each group is reported above.
